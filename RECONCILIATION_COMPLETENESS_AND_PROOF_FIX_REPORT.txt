RECONCILIATION COMPLETENESS AND PROOF FIX REPORT

Branch:
- feature/reconciliation-audit-ui

Scope:
- Read-only reconciliation display/data enrichment only.
- No auth, LAN, escalation, dashboard totals, payment confirmation, or financial record mutation logic changed.
- No auto-confirm or auto-approve behavior added.

Root causes:
- Loading could remain stuck because reconciliation fetch had no timeout or retryable error state.
- /api/reconciliation/open excluded verified/Green rows, so fully matched operational bills were hidden from reconciliation visibility.
- Payment proof matching only used UTR/reference and labeled unmatched payments as Manual too broadly.
- Frontend had no proof-status indicator separating invoice PDF availability from payment proof availability.

Backend changes:
- /api/reconciliation/open now includes all operational bills by default.
- Exclusions remain limited to:
  - TEST-*
  - ARCH-*
  - HARDENING-*
  - is_test_data=true
- Verified/Green fully matched rows are included unless the frontend filters hide them.
- Added count diagnostic headers:
  - X-Reconciliation-Total-Considered
  - X-Reconciliation-Rows-Returned
  - X-Reconciliation-Excluded-Test-Prefix
  - X-Reconciliation-Excluded-Archive-Prefix
  - X-Reconciliation-Excluded-Hardening-Prefix
  - X-Reconciliation-Excluded-Test-Data

Proof matching:
- Deterministic evidence matching now uses:
  1. UTR/reference exact match
  2. exact amount plus 24-hour timestamp proximity
  3. payment mode classification for Manual vs Not Recorded
- SMSAlert matches return:
  - source = SMS
  - proof_label = View SMS Proof
  - proof_url = /api/reconciliation/proof/sms/{id}
- BankAlert matches return:
  - source = Email when sender contains @
  - source = Bank otherwise
  - proof_label = View Email Proof or View Bank Alert
  - proof_url = /api/reconciliation/proof/bank/{id}
- No proof links are fabricated.

Frontend changes:
- Added AbortController timeout via getOpenReviewsWithTimeout.
- Timeout is 15 seconds.
- Timeout message: "Reconciliation request timed out. Please retry."
- Loading is cleared in finally.
- Error state has Retry button.
- No fallback to /reviews/open or /api/reviews/open.
- Main table keeps View PDF behavior and adds proof status:
  - Invoice PDF available / Payment proof available
  - Invoice PDF available / Missing payment proof
  - Payment proof available
  - Missing payment proof
- Active filter count is shown with existing Clear Filters control.
