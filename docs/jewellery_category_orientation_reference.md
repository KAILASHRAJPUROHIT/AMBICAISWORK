## Key takeaways for orientation logic

1. **WATI is the one genuine ambiguity** — confirm with the user if a separate MANGALSUTRA folder exists; if so, WATI is unambiguously the earring per their own description.
2. Two clean buckets:
   - **Lies flat, face-up**: rings, bangles, kadas, tops, bali, lockets/pendants, chains, necklaces, mala, mangalsutra, nose pins
   - **Hangs/dangles vertically**: jhumka, wati/bugadi-style, generic dangle earrings, maang tikka — orientation matters most here since upside-down/sideways is visibly wrong even to non-experts
3. Brooch, cufflinks, armlet/bajuband: insufficient info — flag for a follow-up targeted search once exact folder names for the remaining ~44 unseen categories are available.
