Root Cause of Login Loop:
1. Field name mismatch between backend response ('token') and frontend storage expectation ('session_token').
2. Concurrent usage of multiple storage keys ('token', 'session_token', 'aradhana_session_token') causing race conditions during AuthProvider initialization.
3. Lack of explicit debug tracing during the P0 regression state.

- Backend OTP Verify Success: returns {"success": true, "session_token": "...", "user": {...}}
- Frontend Storage Key: "aradhana_session_token"
- Frontend User Key: "user"
- Authenticated API Header: "X-Session-Token"
- Backend Validation: GET /api/auth/validate-session (verifies X-Session-Token)
