MASTER CONSOLE ENDPOINT FIX REPORT

Root cause:
- GET /api/admin/users, /api/admin/security/stats, and /api/admin/system/mode returned 422 because require_owner used Depends(lambda r, d: require_role(...)).
- FastAPI treated r and d as required query parameters instead of injecting Request and db.
- GET /api/admin/financial/health returned 404 because the route was declared after the SPA catch-all route /{full_path:path}.

Fix:
- Replaced require_owner with an explicit dependency signature:
  - request: Request
  - db: Session = Depends(get_db)
  - delegates to require_role(["OWNER", "ADMIN"], request, db)
- Moved /api/admin/financial/health before the SPA catch-all and removed the unreachable duplicate after the catch-all.
- Added maintenance boolean to /api/admin/system/mode response.

Files changed:
- backend/review_api.py
