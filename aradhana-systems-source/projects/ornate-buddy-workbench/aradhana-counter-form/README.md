# Aradhana Jewellers – Local Counter Form

A local browser form based on the Aradhana counter slip. It uses verified live rates from:

`https://aradhana-gold-monitor.onrender.com/api/rate`

## What it does

- Separate **New Gold, New Silver, Old Gold, Old Silver** sections.
- New items: staff selects the item and enters **weight + purity**. Rate, metal value, GST (3%), and total are automatic.
- Old items: up to 3 rows each for Gold and Silver. **Weight, purity, amount are all manual**.
- **Final Bill Amount = New Gold total + New Silver total only.** Old amounts are never subtracted.
- Date/ref are generated by the server.
- Every submission is saved to `data/submissions.jsonl`.
- The same slip summary is sent by WhatsApp to **+91 94226 82086**.
- WhatsApp sending is blocked unless the linked account is exactly **+91 89561 43245**.

## Rate logic

The form reads the monitor's full `/api/rate` state, including its verified Gold and Silver state.

Gold standard purities preserve the monitor's business rates:

- 999/24KT -> monitor `rate24kt`
- 916/22KT -> monitor `rate22kt`
- 750/18KT -> monitor 18KT variant
- Other purity -> monitor loaded 999 base x entered fineness / 1000

Silver:

- 999 -> monitor Silver Pure rate
- 975 -> monitor Silver Ornament rate
- Other purity -> Silver Pure x entered fineness / 999

The server re-fetches and re-calculates on **Submit**, so the saved/WhatsApp total does not trust the browser's displayed calculation.

## Windows quick start

1. Install **Node.js 20+** once.
2. Double-click `start.bat`.
3. First run installs dependencies.
4. A WhatsApp QR appears in the command window. On **+91 89561 43245**, open WhatsApp -> Settings -> Linked Devices -> Link a Device and scan it.
5. Open `http://localhost:8095` on the same PC.
6. For another device on the same shop LAN, use the `LAN: http://...:8095` address printed in the command window.

The WhatsApp session is stored locally under `data/wa-session` so you normally scan once.

## Important

`whatsapp-web.js` is an unofficial linked-device client, matching the mechanism already used by the local Aradhana Gold Monitor. Keep this for the single fixed internal recipient configured here; do not repurpose it for bulk customer broadcasts.

To change item dropdowns, port, rate source, or fixed WhatsApp numbers, edit `config.json` and restart.
