# Indian/Maharashtrian Jewellery Category Reference

Compiled 2026-08-18, revised 2026-08-19 for CaptureCam/capture_tool.py
orientation-aware capture. This revision maps the 57 EXACT stock categories
from the retailer's real Excel stock report (label/code-prefix pairs) onto
orientation guidance, deduplicating by karat suffix ("18"/"22"/"20" are
purity, not different physical items) where the orientation is identical
across karats.

Method: web research across jewellery retailer/wholesaler sites (Totaram
Jewelers, BlueStone, CaratLane, Mangalsutraonline, Kalyan Jewellers, Tanishq,
Manubhai Jewellers, Kushal's, Wamanharipethesons, IndiaMART regional listings,
Marathi/Maharashtrian jewellery glossaries, etc.), specifically targeting
Marathi/regional terminology (DULL, MANGOTA, KAAN CHAIN, BAJU BANDH, MOTI
NATH, MS LONG, MSS-SHORT) rather than assuming English-cognate meanings.
Reference URLs are product/category pages — the hero photo on each page is
the reference shot, not necessarily a direct image file URL. Where a real
search attempt did not turn up a confirming source, that is stated honestly
rather than guessed, since this data drives automatic image rotation.

## Key takeaways

1. **Categories where orientation matters most (dangles/hangs — upside-down
   or sideways is visibly wrong even to a non-expert):** EARRING, JHUMKA,
   KAAN CHAIN, TIKKA, and the two NATH variants (MOTI NATH, NATH) — these
   all have a clear top-attachment point and a clear "hanging" direction that
   must be preserved. BAJU BANDH also has a directional element (which way
   the plaque/motif faces) but is more forgiving since it's an open curve
   rather than a true hanging piece.
2. **Categories that are safe to treat generically (flat, symmetric,
   forgiving of small tilt errors):** all rings, all bangles/kada
   (baby/gents/ladies), all bracelets, BALI, TOPS, DULL, all gold coin
   weights, and — with the "bail at top" rule applied — lockets, pendants,
   and pendant sets.
3. **Necklace-family items** (CHAIN, HAAR CHAIN, NECKLACE, NECKLACE SET,
   FANCY MALA, MS LONG, MSS-SHORT) need a symmetric-curve layout with the
   clasp hidden and any focal pendant/motif centered at the bottom — not a
   strict up/down orientation, but a left-right symmetry constraint.
4. **Genuine remaining gaps, ranked by how much they matter:**
   - **MANGOTA (MG22)** is the single biggest open question — no source
     confirms the term directly; the mango/paisley-motif-pendant theory is
     plausible but unverified. This is exactly the kind of case that burned
     the earlier WATI guess — recommend checking a real MANGOTA folder photo
     against the owner directly before trusting this entry, rather than
     shipping it on inference alone.
   - **DULL (DL22)** — identified as a small, low-gram stud-earring line via
     trade listings, but no branded product photo confirms the shape;
     treated as low confidence and grouped with TOPS/BALI as a flat-lay item,
     which is the safer default even if the specific identification is off.
   - **BABY RING, BABY BRACLET, GENTS BRACELET** — the underlying orientation
     logic (rings flat face-up; flexible bracelets as an open curve) is high
     confidence by analogy to their adult/ladies counterparts, but no
     baby/gents-specific hero photo was found, so the specific reference URLs
     are moderate confidence only.
   - Everything else in the 57 reached **high or moderate** confidence with
     a real supporting source.
5. Gold coins (14 of the 57 labels) are trivial: one shared rule (flat,
   face up, embossed motif toward camera) covers all weight variants.

### Gold coins

All 14 weight variants are the same flat, round, stamped coin — see the
orientation section above for the shared "flat, face up, embossed motif
toward camera" rule. Weight is already known exactly from the category
label itself (e.g. "Gold Coin 5 Gm" = 5.000 g); what's added here is an
honest note on diameter, since no Indian retailer (Totaram, Tanishq,
MMTC-PAMP) listing found in this pass states a diameter-by-weight table.
International bullion-coin size charts (not India-specific, and not
necessarily the same mint standard) suggest roughly 13 mm at the ~1.5 g end
up to ~30–33 mm at the ~1 oz (31.1 g) end, scaling roughly with the square
root of weight — offered only as a rough physical-plausibility check, not a
sourced Indian-market figure.
